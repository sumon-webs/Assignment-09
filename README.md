# 📌 Project Overview

DocAppoint is a full-stack doctor appointment booking platform developed with Next.js. It provides an intuitive interface for users to search doctors, view detailed profiles, and book appointments efficiently. The application leverages the Next.js App Router, Server Components, and secure authentication to deliver a fast, scalable, and responsive user experience.

# 🚀 Run Locally

## 1. Clone the repositories

```bash
git clone https://github.com/sumon-webs/DocAppoint.git
git clone https://github.com/sumon-webs/DocAppoint-server.git
```

## 2. Install dependencies

### Client

```bash
cd DocAppoint
npm install
```

### Server

```bash
cd DocAppoint-server
npm install
```

## 3. Configure Environment Variables

Create a `.env.local` file in the client and a `.env` file in the server.

Example:

```env
NEXT_PUBLIC_API_URL=
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=
MONGODB_URI=
```

## 4. Run the project

### Client

```bash
npm run dev
```

### Server

```bash
npm run dev
```
